# StratoBusters - CanSat Project Website

A modern, minimalistic website for the StratoBusters CanSat project featuring:
- 🚀 Interactive 3D satellite model
- 📸 Auto-loading image gallery
- 📰 File-based blog system
- 👥 Team showcase
- 🌓 Light/Dark theme support
- 📱 Fully responsive design

## Quick Start

1. Upload all files to your web server
2. Add your content (see `SETUP.md` for details)
3. Done! The website is ready.

## Features

- **Easy Content Management**: Add images and blog posts by simply editing JSON files
- **3D Model Support**: Display your satellite STL model on the homepage
- **Theme Switching**: Light and dark themes with persistent user preference
- **Responsive**: Works perfectly on desktop, tablet, and mobile devices
- **Modern Design**: Clean, minimalistic, tech-focused aesthetic
