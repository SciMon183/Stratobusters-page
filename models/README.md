# 3D Models

Place your satellite 3D model here in STL format.

## File Format
- **Format**: STL (Stereolithography)
- **Filename**: `satellite.stl`
- **Location**: `models/satellite.stl`

## How to Add Your Model

1. Export your 3D model as STL format from your CAD software
2. Name it `satellite.stl`
3. Place it in this `models/` folder
4. The website will automatically load and display it on the homepage

## Note

If no STL file is found, the website will automatically display a placeholder 3D model of a satellite.

## Supported Software

You can export STL files from:
- SolidWorks
- Fusion 360
- Blender
- AutoCAD
- FreeCAD
- And many other CAD programs
