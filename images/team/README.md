# Team Photos

Place team member photos here.

## File Naming

Name your images descriptively, for example:
- `member1.jpg`
- `john-doe.jpg`
- `team-lead.jpg`

## Image Requirements

- **Format**: JPG, PNG, or WebP
- **Recommended Size**: 300x300px to 500x500px (square)
- **File Size**: Keep under 500KB for fast loading

## Usage

Reference images in `data/team.json`:

```json
{
  "name": "John Doe",
  "role": "Project Lead",
  "image": "images/team/john-doe.jpg",
  "bio": "Team member bio here"
}
```

## Placeholder

If an image is missing, the website will try to use a placeholder. Make sure to add actual team photos for the best experience.
