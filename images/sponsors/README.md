# Sponsor Logos

Place your sponsor logo images in this folder.

## File Requirements:
- **Format**: PNG or SVG (PNG recommended for transparency)
- **Naming**: 
  - `sponsor1.png` - First sponsor logo
  - `sponsor2.png` - Second sponsor logo
- **Recommended Size**: 300-400px wide, transparent background
- **Aspect Ratio**: Flexible, but logos will be displayed at max 120px height

## How to Update Sponsors:

1. Add your sponsor logo images to this folder
2. Update the sponsor links in `index.html`:
   - Change `href="https://example.com/sponsor1"` to your sponsor's website
   - Change `href="https://example.com/sponsor2"` to your sponsor's website
3. Update the alt text for accessibility:
   - Change `alt="Sponsor 1"` to your sponsor's name
   - Change `alt="Sponsor 2"` to your sponsor's name

## Adding More Sponsors:

To add more sponsors, add more sponsor cards in the `.sponsors-grid` section in `index.html` following the same pattern.
